개인정보 처리방침

마지막 업데이트: 2026년 9월 24일

개요

이 정책은 방문 시 수집되는 정보와 수집되지 않는 정보를 설명합니다. 간단한 버전: 사용자 계정을 운영하지 않으며, 데이터를 판매하지 않습니다.

수집하지 않는 정보

등록하거나 로그인하도록 요구하지 않습니다. 이름, 이메일 주소, 전화번호 또는 기타 개인 정보를 수집하지 않습니다.

브라우저에 저장된 정보

테마 선택(밝음 또는 어두움)은 브라우저 로컬 저장소에 저장되어 다음에 사이트를 방문할 때 기억합니다.

기사 조회수를 의미 있게 유지하기 위해, 동일한 브라우저 세션 내에서 동일한 기사를 반복적으로 열어도 중복 계산되지 않도록 세션 저장소에 마커가 유지됩니다. 세션 저장소는 브라우저를 닫을 때 자동으로 지워집니다.

또한, 분석 도구들은 쿠키나 로컬 저장소에 무작위 식별자를 저장하여 한 번의 방문 중에 본 페이지를 익명 세션으로 그룹화할 수 있습니다. 이 식별자들은 사용자가 누구인지 드러내지 않으며, 브라우저 설정에서 언제든지 지울 수 있습니다.

집계 통계

각 기사가 열리는 횟수를 셉니다. 이는 익명의 총계만 해당하며: IP 주소, 장치 식별자 또는 사용자 프로필은 함께 저장되지 않습니다.

콘텐츠 전송 제공업체(Cloudflare)는 웹 서버처럼 페이지를 전달하고 사이트를 남용으로부터 보호하기 위해 표준 기술 요청 데이터(예: IP 주소)를 처리합니다. 이 데이터는 사용자에 대한 프로필을 구축하는 데 사용되지 않습니다.

분석

사이트가 어떻게 사용되는지(예: 어떤 기사가 읽히는지, 방문자가 어디서 오는지) 이해하기 위해 Google Analytics(Google 태그 관리자를 통해 로드)를 사용합니다. 이는 Google에서 제공하며, 데이터 처리는 Google 개인정보처리방침에 설명되어 있습니다.

또한 히트맵과 익명화된 세션 녹화를 통해 방문자가 사이트를 어떻게 사용하는지 이해하기 위해 Microsoft Clarity도 사용합니다. 녹화는 입력 필드를 마스킹하며 이름이나 연락처 세부 정보와 연결되지 않습니다.

Clarity는 Microsoft에서 제공하며, 해당 데이터 처리는 Microsoft 개인정보처리방침에 설명되어 있습니다. 추적을 원하지 않는 경우, 콘텐츠 차단 브라우저 확장 프로그램으로 googletagmanager.com과 clarity.ms 스크립트를 차단하거나 이들의 JavaScript를 비활성화할 수 있습니다.

어린이

HotNews는 일반 대상 뉴스 출판물이며 13세 미만의 어린이를 대상으로 하지 않습니다.

이 정책의 변경

사이트가 발전함에 따라 이 정책을 업데이트할 수 있습니다. 이 페이지에 표시된 날짜는 항상 현재 버전을 반영합니다.
